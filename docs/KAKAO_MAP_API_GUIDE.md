# 🗺️ 카카오 지도(Kakao Maps API) 연동 및 실제 익산 상권 데이터 로딩 가이드

본 가이드는 카카오 개발자 콘솔에서 **무료 API 키를 발급받아** 익산 및 원광대학교 주변의 실제 모든 음식점, 카페, 편의점, 코인세탁소 정보를 실시간으로 지도에 띄우고 평가 시스템에 연동하는 절차를 안내합니다.

---

## 📌 1. 카카오 API 키 발급 4단계 (약 2분 소요, 100% 무료)

### Step 1. 카카오 개발자 센터 로그인
1. [카카오 개발자 콘솔 (developers.kakao.com)](https://developers.kakao.com) 접속 및 카카오 계정 로그인
2. 상단 메뉴의 **[내 애플리케이션]** 클릭

### Step 2. 애플리케이션 추가
1. **[애플리케이션 추가하기]** 클릭
2. 앱 이름: `익산 로컬 라이프 지도` (원하는 이름 입력)
3. 사업자명: `원광대 자취생 프로젝트` (자유 입력)
4. **[저장]** 클릭

### Step 3. Web 플랫폼 사이트 도메인 등록 (가장 중요 ⚠️)
*카카오 지도는 보안상 등록된 도메인에서만 지도를 표시합니다.*
1. 생성된 애플리케이션 상세 페이지 좌측 메뉴에서 **[앱 설정] > [플랫폼]** 클릭
2. **[Web 플랫폼 등록]** 클릭
3. **사이트 도메인**에 아래 2개 주소를 한 줄씩 입력 후 저장:
   ```
   http://localhost:5173
   http://localhost:5000
   ```

### Step 4. 앱 키 확인 및 복사
좌측 메뉴의 **[앱 설정] > [앱 키]** 클릭:
* **`JavaScript 키`**: 프론트엔드 카카오 지도 렌더링 및 키워드 검색(`kakao.maps.services.Places`)에 사용됩니다.
* **`REST API 키`**: (선택) 백엔드 검색 프록시 연동에 사용됩니다.

---

## ⚙️ 2. 프로젝트에 API 키 적용하는 2가지 방법

### 방법 A. 웹 화면에서 바로 입력 (가장 간편!)
1. 브라우저에서 `http://localhost:5173` 접속
2. 상단 네비게이션 우측의 **[🔑 카카오 지도 API 키 설정]** 버튼 클릭
3. 복사한 **JavaScript 키**를 붙여넣고 **[저장 및 지도 연동]** 클릭
4. 즉시 카카오 지도가 활성화되며 익산시 실제 상권 검색이 가동됩니다!
   *(입력한 키는 브라우저 `localStorage`에 안전하게 보관되어 새로고침해도 유지됩니다)*

---

### 방법 B. 환경 변수(`.env`) 파일에 설정

#### 1) 프론트엔드 설정
`frontend/.env` 파일 생성 후 아래 내용 입력:
```env
VITE_KAKAO_JS_KEY=여기에_발급받은_JavaScript_키를_입력하세요
```

#### 2) 백엔드 설정 (선택 사항)
`backend/.env` 파일 생성 후 아래 내용 입력:
```env
KAKAO_REST_API_KEY=여기에_발급받은_REST_API_키를_입력하세요
```

---

## 🔍 3. 실제 익산 상권 검색 & 5대 평가 연동 메커니즘

1. **실제 카카오 POI 실시간 검색**:
   * 지도 상단 검색창에 `"원광대 치킨"`, `"신동 백반"`, `"신동 빨래방"`, `"익산 카페"` 등을 검색하면, 카카오 로컬 데이터베이스의 실제 상호명, 도로명 주소, 전화번호, 카카오맵 링크가 실시간으로 지도에 마커로 핀포인트됩니다.
2. **원클릭 로컬 라이프 평가 DB 자동 동기화**:
   * 카카오 지도상의 마커나 검색 결과를 클릭하면 백엔드의 `/api/places/sync-kakao` API가 호출됩니다.
   * 이미 다른 원광대생이 리뷰를 남긴 곳이라면 기존 4축 평점(혼밥, 가성비, 동선, 시설)과 배지가 즉시 팝업에 나타납니다.
   * 아직 아무도 평가하지 않은 신규 매장이라도 즉시 로컬 DB에 자동 편입되어, 내가 첫 번째로 **[✍️ 리뷰 작성]**을 통해 4축 점수와 AI 실시간 태그를 등록할 수 있습니다!
3. **익산다로움 및 원광대 도보 시간 자동 산출**:
   * 실시간으로 가져온 위경도 좌표를 바탕으로 원광대 북문/대학로 기준 실제 도보 분(min)이 오토매틱으로 계산됩니다.
